# Flutter app

This is the mobile client. Generate the platform host files with `flutter create .`, then implement the two-screen UX from the root `AGENTS.md`:

- Login
- Home / Dashboard with embedded QR scanner, today's state, monthly summaries, and attendance history

Keep API, authentication, device, Wi-Fi, and local-storage code in `lib/services/`. Add models, screens, widgets, and utilities using the structure already created.
